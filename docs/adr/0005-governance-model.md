# ADR-0005: Governance model

> [!NOTE]
> **Architecture decision: accepted.**

- **Date:** 2026-09-14
- **Deciders:** Founding maintainer
- **Supersedes:** none
- **Superseded by:** none
- **Related:** [GOVERNANCE.md](../../GOVERNANCE.md), [MAINTAINERS.md](../../MAINTAINERS.md), [ADR index](README.md)

## Context and problem statement

The project needed rules for how decisions are made and who makes them.

## Decision outcome

- Maintainers are listed in [MAINTAINERS.md](../../MAINTAINERS.md).
- Decisions are made through pull requests and the RFC process.
- A pull request that changes what an accepted ADR decides adds a superseding ADR.
- Bigger changes go through the [RFC process](../rfcs/README.md).

## Consequences

- Decisions are reviewable and findable.
- The governance page is in the repository root.

## Confirmation

- The governance page is in the repository root.
- Maintainers are listed in [MAINTAINERS.md](../../MAINTAINERS.md).
