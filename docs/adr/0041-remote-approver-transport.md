# ADR-0041: Remote approver transport

> [!NOTE]
> **Architecture decision: deferred.**
> Deferred to v0.6.

- **Date:** 2026-09-14
- **Deciders:** Founding maintainer
- **Supersedes:** none
- **Superseded by:** none
- **Related:** [Approval protocol](../spec/approval-protocol.md)

## Decision outcome

Remote approvers are planned for v0.6 through signed webhooks.
The question is recognized but intentionally postponed.

## Consequences
- Remote approvals require an explicit opt-in.
- No telemetry is sent.
