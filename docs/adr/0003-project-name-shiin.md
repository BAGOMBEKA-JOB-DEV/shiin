# ADR-0003: Project name: Shiin

> [!NOTE]
> **Architecture decision: accepted.**

- **Date:** 2026-09-14
- **Deciders:** Founding maintainer
- **Supersedes:** none
- **Superseded by:** none
- **Related:** [ADR index](README.md)

## Context and problem statement

The project needed a name before documentation, specifications, and code could be written.
The name had to be short, memorable, pronounceable, and not conflict with existing open-source projects.

## Considered options

1. Shiin
2. Latch
3. Gatekeeper
4. AgentGuard

## Decision outcome

Chosen option: Shiin.

- The name is short, easy to type, and easy to pronounce.
- The former working name is recorded here and nowhere else.

## Consequences

- The project is named Shiin.
- The command-line binary is `shiin` and the daemon is `shiind`.

## Confirmation

- The name was checked against existing open-source projects.
- The former working name appears only in this ADR and the landscape page.
