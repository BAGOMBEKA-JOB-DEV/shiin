# Installation

> [!WARNING]
> **Design intent: not implemented.**
> Planned for v0.1. Nothing on this page works yet.

## Prerequisites

- Rust with rustup, using the pinned toolchain.
- A supported host: Linux or macOS.

## Install

```console
$ cargo install --path .
```

## Verify

```console
$ shiin doctor
```

## Update

```console
$ cargo install --path . --force
```
